# Dişli Atölyesi · Gear Workshop

Dişlileri diz, motorun gücü saatlere ulaşsın

Boş bir yuvaya dokununca dişli takılır, yeniden dokununca çıkar. Yan yana duran dişliler birbirini çevirir; çapraz değil. Mavi motordan başlayan zinciri tüm saatlere ulaştır. Dişli sayın sınırlıdır ve kayalara dişli takılmaz.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Özgün Oyunlar merkez uygulamasının oyunu; ortak motor: [ozgun-motoru](https://github.com/taktemurr-ops/ozgun-motoru).
